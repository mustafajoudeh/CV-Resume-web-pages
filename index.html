About Me

I’m a .NET Backend Developer focused on building reliable, maintainable, and database-driven applications using C#, .NET, and ASP.NET Core.

My development approach is based on strong programming fundamentals, including Object-Oriented Programming, Data Structures, Algorithms, and relational database design. I apply these concepts to create backend solutions that are organized, understandable, and built to support real business requirements.

I have hands-on experience developing RESTful APIs and database-driven applications using ASP.NET Core Web API, ADO.NET, Entity Framework Core, and SQL Server. I also work with layered architecture to separate responsibilities and make applications easier to maintain and extend.

I’m particularly interested in business systems where backend development, data, security, and clear system design come together to solve practical problems.
